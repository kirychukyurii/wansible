# Webitel 26.4 — Фаза 1: план імплементації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новий каркас wansible, що розгортає Webitel 26.4 (чиста інсталяція) на Debian 12/PG15 та Debian 13/PG18, single- і multi-host, за спекою `docs/superpowers/specs/2026-06-10-webitel-26.4-redesign-design.md`.

**Architecture:** Хост-центричний інвентар (`services` список → групи через constructed plugin), site.yml з tier-плейбуків, тонкі ролі за конвенціями спеки (defaults з префіксом, validate/install/configure, handlers через listen, без `.bootstrap` і regexp-патчингу пакетних файлів).

**Tech Stack:** ansible-core ≥2.16, колекції community.general/postgresql/rabbitmq, ansible.posix, ansible.utils; ansible-lint (production), yamllint.

**Scope фази 1:** базовий набір сервісів (core, engine, call_center, flow_manager, storage, messages, logger, cases, media_exporter, frontend) + інфраструктура (consul single, postgres standalone, rabbitmq single, freeswitch, rtpengine, opensips, nginx, grafana). Опціональні сервіси (portal, fts, wfm, dsa, meetings, webrtc_rec, im_*) додаються окремим міні-планом після Task 9 (discovery пакетів) — їхні ролі механічно повторюють патерн Task 11.

**Верифікація:** для кожного таска — `ansible-lint` + `--syntax-check` (запускаються локально без цільових хостів). Повна runtime-перевірка — Task 15 на тестових VM (Debian 12 і 13). Runtime-кроки, які неможливо перевірити локально, позначені `[VM]`.

**Коміти:** кроки-коміти виконуються лише під час виконання плану, після окремого підтвердження користувача (на момент написання плану коміти заборонені).

- [ ] **Step 2: `playbooks/preflight.yml`**

```yaml
---
- name: Preflight checks
  hosts: all
  gather_facts: true
  any_errors_fatal: true
  vars_files:
    - vars/known_services.yml
  tags: [always]
  tasks:
    - name: Validate services against known list
      ansible.builtin.assert:
        that: >-
          hostvars[inventory_hostname].services | default([])
          | difference(webitel_known_services) | length == 0
        fail_msg: >-
          Unknown services on {{ inventory_hostname }}:
          {{ hostvars[inventory_hostname].services | default([]) | difference(webitel_known_services) }}.
          Valid services: {{ webitel_known_services | join(', ') }}
        quiet: true

    - name: Require Debian 12 (bookworm) or 13 (trixie)
      ansible.builtin.assert:
        that:
          - ansible_facts.distribution == 'Debian'
          - ansible_facts.distribution_major_version in ['12', '13']
        fail_msg: >-
          Unsupported OS: {{ ansible_facts.distribution }} {{ ansible_facts.distribution_major_version }}.
          Webitel 26.4 supports Debian 12 (PostgreSQL 15) and Debian 13 (PostgreSQL 18).
        quiet: true

    - name: Derive PostgreSQL major version from Debian release
      ansible.builtin.set_fact:
        pg_major: "{{ '15' if ansible_facts.distribution_major_version == '12' else '18' }}"

    - name: Require amd64 on PostgreSQL hosts (webitel extension is amd64-only)
      ansible.builtin.assert:
        that: ansible_facts.architecture == 'x86_64'
        fail_msg: "PostgreSQL with webitel extension requires amd64, got {{ ansible_facts.architecture }}"
        quiet: true
      when: "'postgres' in (services | default([]))"

    - name: Require amd64 on FreeSWITCH hosts (modules are amd64-only)
      ansible.builtin.assert:
        that: ansible_facts.architecture == 'x86_64'
        fail_msg: "FreeSWITCH modules require amd64, got {{ ansible_facts.architecture }}"
        quiet: true
      when: "'freeswitch' in (services | default([]))"

    - name: Require S3 repo credentials
      ansible.builtin.assert:
        that:
          - webitel_repo_s3_access_key | default('') | length > 0
          - webitel_repo_s3_access_key != 'CHANGE_ME'
          - webitel_repo_s3_secret_key | default('') | length > 0
          - webitel_repo_s3_secret_key != 'CHANGE_ME'
        fail_msg: "Set webitel_repo_s3_access_key / webitel_repo_s3_secret_key (see group_vars/all/vault.yml.example)"
        quiet: true

    - name: Require SignalWire key on FreeSWITCH hosts
      ansible.builtin.assert:
        that:
          - freeswitch_signalwire_key | default('') | length > 0
          - not freeswitch_signalwire_key.startswith('pat_CHANGE')
        fail_msg: "Set freeswitch_signalwire_key (SignalWire Personal Access Token)"
        quiet: true
      when: "'freeswitch' in (services | default([]))"

    - name: Require LetsEncrypt settings when enabled
      ansible.builtin.assert:
        that:
          - nginx_site_name | default('') | length > 0
          - nginx_mail_address | default('') | length > 0
        fail_msg: "nginx_letsencrypt=true requires nginx_site_name and nginx_mail_address"
        quiet: true
      when:
        - "'nginx' in (services | default([]))"
        - nginx_letsencrypt | default(false) | bool

- name: Preflight topology checks (cross-host)
  hosts: localhost
  gather_facts: false
  any_errors_fatal: true
  tags: [always]
  tasks:
    # datacenter гарантовано визначений для всіх хостів (дефолт dc1 у group_vars/all.yml)
    - name: Single rtpengine/opensips/postgres per datacenter (phase 1)
      ansible.builtin.assert:
        that: >-
          groups[item] | default([])
          | map('extract', hostvars)
          | groupby('datacenter')
          | map(attribute='1')
          | map('length')
          | select('gt', 1)
          | list | length == 0
        fail_msg: "Phase 1 supports exactly one '{{ item }}' host per datacenter"
        quiet: true
      loop: [rtpengine, opensips, postgres, consul_server, rabbitmq]
```
