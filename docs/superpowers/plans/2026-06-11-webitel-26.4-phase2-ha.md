# Webitel 26.4 — Фаза 2: HA (Failover 1 ДЦ + Warm standby 2 ДЦ)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Додати HA-розгортання Webitel 26.4 — кластери Consul (server+agent), Nomad (server+client), Patroni (PostgreSQL, DCS=Consul), RabbitMQ — у той самий каркас, що й фаза 1. Режим вмикається інвентарем; ролі працюють і в Failover (1 ДЦ, один кластер), і в Warm standby (2 ДЦ, per-DC кластери).

**Architecture:** Нова роль `pki` генерує CA+серти на контролері (`community.crypto`) і розкладає в `/etc/ssl/app/`. `consul` розширюється до cluster+agent+TLS+gossip-encrypt+DNS-forward. Нові ролі `nomad` (server/client, плагін опційно) і `patroni` (PostgreSQL під Patroni з Consul DCS, замінює `postgres` в HA-інвентарі). `rabbitmq` отримує кластерний режим (erlang cookie + /etc/hosts + serial bootstrap). Webitel-сервіси в HA підключаються через локальний consul agent до `master.{{ patroni_scope }}.service.consul` та `rabbitmq.service.consul`.

**Tech Stack:** ansible-core ≥2.16, community.crypto (новий), community.general/postgresql/rabbitmq, consul/nomad/patroni (deb з HashiCorp/Debian репо), cfssl-сумісні CA-параметри (ed25519).

**Scope:** Кластери піднімаються і реєструються; **Nomad jobs НЕ деплояться** (фаза 3). Крос-ДЦ реплікація (Patroni standby cluster, RabbitMQ federation) — фаза 3. etcd-DCS і 3-ДЦ stretch — фаза 3.

**Верифікація:** кожен таск — `ansible-lint` + `--syntax-check` (локально). Runtime-перевірка кластерів — Task P9 на VM (запускає користувач). Кроки `[VM]` не виконуються агентом.

**Коміти:** НЕ робити (як у фазі 1) — лишати в робочому дереві, поки користувач не дозволить.

```yaml
---
- name: Ensure local PKI directory exists (controller)
  ansible.builtin.file:
    path: "{{ pki_local_dir }}"
    state: directory
    mode: "0700"
  delegate_to: localhost
  run_once: true
  become: false

- name: Generate CA private key (controller)
  community.crypto.openssl_privatekey:
    path: "{{ pki_local_dir }}/ca-key.pem"
    type: "{{ pki_key_type }}"
    mode: "0600"
  delegate_to: localhost
  run_once: true
  become: false

- name: Generate CA CSR (controller)
  community.crypto.openssl_csr:
    path: "{{ pki_local_dir }}/ca.csr"
    privatekey_path: "{{ pki_local_dir }}/ca-key.pem"
    common_name: "{{ pki_ca_cn }}"
    organization_name: "{{ pki_ca_o }}"
    basic_constraints:
      - "CA:TRUE"
    basic_constraints_critical: true
    key_usage:
      - keyCertSign
      - cRLSign
    key_usage_critical: true
  delegate_to: localhost
  run_once: true
  become: false

- name: Self-sign CA certificate (controller)
  community.crypto.x509_certificate:
    path: "{{ pki_local_dir }}/ca.pem"
    privatekey_path: "{{ pki_local_dir }}/ca-key.pem"
    csr_path: "{{ pki_local_dir }}/ca.csr"
    provider: selfsigned
    selfsigned_not_after: "+{{ pki_cert_validity_days }}d"
    mode: "0644"
  delegate_to: localhost
  run_once: true
  become: false
```

- [ ] **Step 5: `roles/pki/tasks/node.yml`** (per-host серти: server-профіль `<host>.pem` + client-профіль `peer-<host>.pem`)

```yaml
---
- name: Generate node private keys (controller)
  community.crypto.openssl_privatekey:
    path: "{{ pki_local_dir }}/{{ item }}-key.pem"
    type: "{{ pki_key_type }}"
    mode: "0600"
  delegate_to: localhost
  become: false
  loop:
    - "{{ inventory_hostname }}"
    - "peer-{{ inventory_hostname }}"

- name: Generate node CSRs (controller)
  community.crypto.openssl_csr:
    path: "{{ pki_local_dir }}/{{ item.name }}.csr"
    privatekey_path: "{{ pki_local_dir }}/{{ item.name }}-key.pem"
    common_name: "{{ inventory_hostname }}"
    subject_alt_name: "{{ item.san }}"
    extended_key_usage: "{{ item.eku }}"
  delegate_to: localhost
  become: false
  loop:
    - name: "{{ inventory_hostname }}"
      san:
        - "DNS:{{ inventory_hostname }}"
        - "DNS:localhost"
        - "IP:{{ ansible_facts.default_ipv4.address }}"
        - "IP:127.0.0.1"
      eku: [serverAuth, clientAuth]
    - name: "peer-{{ inventory_hostname }}"
      san:
        - "DNS:{{ inventory_hostname }}"
        - "IP:127.0.0.1"
      eku: [clientAuth]
  loop_control:
    label: "{{ item.name }}"

- name: Sign node certificates with CA (controller)
  community.crypto.x509_certificate:
    path: "{{ pki_local_dir }}/{{ item }}.pem"
    csr_path: "{{ pki_local_dir }}/{{ item }}.csr"
    ownca_path: "{{ pki_local_dir }}/ca.pem"
    ownca_privatekey_path: "{{ pki_local_dir }}/ca-key.pem"
    provider: ownca
    ownca_not_after: "+{{ pki_cert_validity_days }}d"
    mode: "0644"
  delegate_to: localhost
  become: false
  loop:
    - "{{ inventory_hostname }}"
    - "peer-{{ inventory_hostname }}"

- name: Create remote PKI directory
  ansible.builtin.file:
    path: "{{ pki_remote_dir }}"
    state: directory
    owner: root
    group: root
    mode: "0755"

- name: Copy CA and node certs to host
  ansible.builtin.copy:
    src: "{{ pki_local_dir }}/{{ item.src }}"
    dest: "{{ pki_remote_dir }}/{{ item.dest }}"
    owner: root
    group: root
    mode: "{{ item.mode }}"
  loop:
    - { src: "ca.pem", dest: "ca.pem", mode: "0644" }
    - { src: "{{ inventory_hostname }}.pem", dest: "{{ inventory_hostname }}.pem", mode: "0644" }
    - { src: "{{ inventory_hostname }}-key.pem", dest: "{{ inventory_hostname }}-key.pem", mode: "0640" }
    - { src: "peer-{{ inventory_hostname }}.pem", dest: "peer-{{ inventory_hostname }}.pem", mode: "0644" }
    - { src: "peer-{{ inventory_hostname }}-key.pem", dest: "peer-{{ inventory_hostname }}-key.pem", mode: "0640" }
  loop_control:
    label: "{{ item.dest }}"
```

    name: systemd-resolved
    enabled: true
    state: started
